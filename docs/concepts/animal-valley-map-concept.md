# Animal Valley Map Concept

Status: work in progress; exploratory reference only.

![Exploratory animal valley map concept](animal-valley-map-concept.png)

The image explores a compact, welcoming animal world with a home clearing, woodland, meadow, stream, bridge and hilltop lookout. It can support discussion about the overall world shape and how a child might move between places.

This is not an approved map layout or production asset. Locations, labels, mission placement, navigation behavior, visual details and final art remain to be designed. Do not infer that every pictured animal or location belongs in the MVP. The image's source and usage rights have not yet been verified; resolve them before publishing it as product art.

## Design questions

- Which few locations make the world easy for a child aged 6–8 to understand?
- How should the map communicate where a mission is available without adding unnecessary visual clutter?
- What is the simplest keyboard, touch and accessible navigation model?
- Which parts of the concept should change after reviewing the map at phone, tablet and desktop sizes?

Keep this document and the existing MVP development plan aligned as the design evolves. This concept does not authorize implementation of extra missions, regions or subjects.
